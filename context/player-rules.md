# Règles du Joueur — Guerrier D&D 5e

## Actions disponibles par tour

### Action principale
| Action | Effet mécanique |
|--------|----------------|
| **Attaque** | 1 jet d'attaque (1d20+5) vs CA cible, puis dégâts |
| **Esquiver** | Attaques contre toi en désavantage ; avantage sur jets DEX jusqu'au prochain tour |
| **Se désengager** | Déplacement sans provoquer d'attaque d'opportunité |
| **Foncer** | Vitesse doublée (60 pieds = 12 cases) |
| **Aider** | Un allié a l'avantage sur sa prochaine attaque ou test |
| **Se cacher** | Test Discrétion (DEX+1) vs Perception passive des ennemis |
| **Chercher** | Test Perception (SAG+1) pour trouver objets/créatures cachés |
| **Utiliser un objet** | Boire une potion, activer un objet (action complète) |

### Action bonus
| Action | Condition |
|--------|-----------|
| **Deuxième Souffle** | 1×/repos court — récupère 1d10+1 PV instantanément |

### Réaction (1/round, se recharge au début de ton tour)
| Action | Déclencheur |
|--------|------------|
| **Attaque d'opportunité** | Ennemi adjacent quitte ton allonge sans Se désengager → 1 attaque gratuite |

## Calcul des jets d'attaque
- **Épée longue (CaC)** : 1d20 + FOR(+3) + maîtrise(+2) = **1d20+5**, dégâts **1d8+3**
- **Hache de main (CaC)** : 1d20+5, dégâts **1d6+3**
- **Hache de main (lancer)** : 1d20+5, portée 20/60 pieds, dégâts **1d6+3**
- **Critique (20 naturel)** : doubler les dés de dégâts → épée : **2d8+3**
- **Échec critique (1 naturel)** : raté automatiquement, peu importe les bonus

## Règles de déplacement
- **30 pieds** = 6 cases par tour (peut fractionner avant/après action)
- **Terrain difficile** : chaque case coûte 2 cases de mouvement
- **Se relever** (prone) : coûte la moitié de la vitesse (15 pieds)
- **Grappin / escalade** : terrain difficile sauf si maîtrise d'Athlétisme

## Aptitudes de classe — Guerrier
### Deuxième Souffle
- **Fréquence** : 1 fois par repos court ou long
- **Action** : Action bonus
- **Effet** : Récupère **1d10+1** PV (min 2, max 11)
- **Usage tactique** : Idéal sous les 50% de vie, ne pas attendre 0 PV

### Style de combat : Défense (passif)
- +1 à la CA quand tu portes une armure (inclus dans CA 16)

## Conditions qui affectent le joueur
| Condition | Impact |
|-----------|--------|
| **Prone** (à terre) | Désavantage sur tes attaques ; ennemis ont avantage CaC, désavantage distance |
| **Poisonné** | Désavantage sur tes jets d'attaque et tests de caractéristique |
| **Étourdi** | Ne peut pas agir ; ennemis ont avantage ; jets STR/DEX ratés |
| **Agrippé** | Vitesse 0 ; peut tenter un test FOR ou DEX vs FOR de l'agresseur pour se libérer |
