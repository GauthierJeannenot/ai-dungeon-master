API source: https://www.dnd5eapi.co/api/2014/
Original API class-level and spell responses and their SHA-256 digests are
preserved in level7-sources.json. The official SRD is authoritative where
community API class lists differ (Divination is on the cleric spell list).

Additional API class-feature, subclass and spell responses and their SHA-256
digests are preserved in subclass-sources.json.

Local changes: French summaries, curated level-seven character builds using
SRD fixed-average hit points, four SRD subclasses, explicit rule tools and
stateful rests, reactions, concentration and spell effects. Utility narration
and two-dimensional grid geometry retain the limits documented in
../../docs/level7-srd2014.md. This is not a complete SRD spell catalogue.
